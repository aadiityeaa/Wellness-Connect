# WellnessConnect - Therapy Slot Booking and Management System

WellnessConnect is a web platform where **students** can:

1. Sign up, log in, and book therapy slots with the therapist 
2. Take different mental health tests and view their results  
3. See important announcements from the admin
4. Read different articles related to ones particular suffering

**Therapist** can:

1. Log in with predefined credentials(only 1 single admin)  
2. Post announcements  
3. Manage student bookings and see test results for every test taken

The project is built using **PHP**, **MySQL**, **HTML**, **CSS**, and **JavaScript**, and is designed to run locally with a server like **XAMPP**.
